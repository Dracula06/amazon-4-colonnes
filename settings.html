Paramètres de l'extension Amazon

📢 Intégration Discord (Option A)

Permet de partager instantanément une fiche analysée ou une capture d'offre dans un salon Discord via un Webhook officiel.

Obtenu dans les paramètres de votre salon Discord > Intégrations > Webhooks. Le webhook est stocké localement dans votre profil Chrome.

✈️ Intégration Telegram (Option B)

Permet de partager instantanément une fiche analysée ou une capture d'offre directement dans un canal, groupe ou chat Telegram via l'API Bot officielle ou un webhook tiers.

Créé gratuitement en 30 secondes en envoyant /newbot à @BotFather sur Telegram.
Identifiant du canal, du groupe ou de votre compte (pensez à ajouter votre bot en administrateur du canal pour qu'il puisse publier).
Laissez vide si vous utilisez le Token + Chat ID direct. Utile uniquement si vous passez par un relais tiers (Make, n8n, Zapier).

📐 Personnalisation d'affichage

Valeur par défaut recommandée : 1200 px (idéal pour les écrans 1080p avec zoom 125%).

🏷️ Tags Amazon Partenaires (par pays)

Identifiants de suivi par défaut utilisés pour générer les liens rapides affiliés lorsque SiteStripe n'est pas détecté ou en secours. Stockés uniquement localement dans votre profil navigateur.

💾 Sauvegarde & Restauration

Exportez ou importez l'ensemble de vos paramètres (Telegram, Discord, GitHub, tags affiliés, affichage) dans un fichier JSON pour les sauvegarder ou les transférer facilement.
